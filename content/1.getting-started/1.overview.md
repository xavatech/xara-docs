The Xara Business API lets your application create products and tickets for a business, request a customer invoice, and receive a webhook when the customer pays.

The base URL for every request is:

```text
https://graph.usexara.ai/rest/
```

![The API configuration card showing the Xara Graph API base URL and HTTPS protocol](/images/docs/dashboard-api-configuration.png)

*The developer dashboard shows the public Graph API connection details used by every request.*

## The integration flow

::steps
### Create or retrieve a catalog item

Create a product, service, ticket product, or subscription and keep its returned `data.id`. When you create a ticketed event, each tier has a `product_id`. These IDs identify what the customer will pay for.

### Request an invoice

Send the customer's phone number and one or more product IDs to `Payment/initiateInvoice`. Authorize the request with your Bearer API token.

### Store the reference

Every successful invoice response contains a `reference`. Store it with your order so you can match the later payment to your own record.

### Receive the payment webhook

When money arrives, Xara sends `invoice.payment_received` or `invoice.paid` to your registered webhook URL.

### Verify and match the payment

Verify the signature using the raw request body. Use the delivery ID to avoid processing the same webhook twice, then match the payment to the invoice reference you stored.
::

## Credentials and identifiers

The [Xara developer dashboard](https://business.usexara.ai/dashboard/developers) provides these values:

| Credential | Used for |
| --- | --- |
| API token | Authorizing product, ticket, and invoice requests |
| Business ID | Identifying the account in integrations that ask for it; do not pass it to `Payment/initiateInvoice` |
| Webhook secret | Verifying that webhook deliveries came from Xara |

`CatalogItem/create`, `CatalogItem/getAll`, `Ticket/createBusinessTicket`, and `Payment/initiateInvoice` require a Bearer API token. For invoice requests, Xara uses the business connected to that authenticated account.
