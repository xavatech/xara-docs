`xara-tic-tac-toe` is a complete game built the way any game for Xara is: a static page using `@xavatech/xara-game-sdk`. Use it as a starting point.

## Run it

```bash
npm install
npm run dev     # opens with the mock host: both players share the screen
npm test        # the board rules
npm run build   # static files in dist/, ready to host over https
```

## How it is built

The rules live in `src/board.ts`, separate from the screen, so every phone draws the same board from the same moves:

```ts
// The player who started is X; the other is O.
export function replay(moves: Move<{ cell: number }>[], players: Player[]): Cell[] {
  const board: Cell[] = Array(9).fill(null);
  for (const move of moves) {
    const mark = markOf(players, move.user_id);
    if (mark && !board[move.payload.cell]) board[move.payload.cell] = mark;
  }
  return board;
}
```

`src/main.ts` draws that board after every state, and only enables the cells when `xara.isMyTurn()`. A move that wins or fills the board ends the game in the same call, so nobody can move after it:

```ts
const result = winner(next)
  ? { winner_ids: [me], summary: `${mark} wins with three in a row` }
  : isDraw(next)
    ? { winner_ids: [], summary: "It's a draw" }
    : undefined;
await xara.move({ cell }, { result });
```

It also sells a hint for ₦100 with `requestPayment`, using `hint-<session>-<revision>` as the reference so a player is never charged twice for the same hint.
